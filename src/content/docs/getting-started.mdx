## Install

From your local checkout of `anthurium-ai/orca`:

```bash
./install.sh
agent-orca --version
```

## Initialize a repo

In the repo you want to work on:

```bash
agent-orca init --preset go   # or node|python
agent-orca check
agent-orca doctor
```

Starter templates now include commented role examples for Codex/Claude so `--mode auto` works without guesswork.

## Validate and run a blueprint

```bash
agent-orca blueprint lint blueprints/work-default-v1.yaml
agent-orca blueprint run blueprints/work-default-v1.yaml
agent-orca blueprint run blueprints/work-default-v1.yaml --profile strict
agent-orca blueprint evidence --newest
```

The default blueprint in the Orca repo is `blueprints/work-default-v1.yaml`.

Blueprint runs persist state and emit evidence with explicit terminal decisions: `PASS`, `WARN`, or `BLOCK`.

## Task queue and validated work

```bash
agent-orca queue enqueue "Add /healthz endpoint"
agent-orca queue enqueue "Refactor config loading"
agent-orca queue ls --active

# in separate terminals:
agent-orca work --worker coder-1 --mode auto --role coder
agent-orca work --worker coder-2 --mode auto --role coder
```

Each worker creates its own worktree, executes the requested task, then validates completion through the default blueprint.

Fast path for one-off work:

```bash
agent-orca do "Add DELETE /todos/{id} endpoint" --mode auto --role coder
```

Useful recovery and hygiene commands:

```bash
# inspect failures
agent-orca queue ls --failed

# retry one failed item
agent-orca queue retry <item_id>

# retry latest failed item
agent-orca queue retry --latest-failed

# retry all failed items (optionally cap count)
agent-orca queue retry --all-failed --limit 3

# remove stale worker worktrees
agent-orca queue gc
```

Evidence is written per task at:

```text
.agent-orca/runs/queue/<item_id>/evidence.json
```

Blueprint evidence is written alongside queue evidence as:

```text
.agent-orca/runs/queue/<item_id>/blueprint-state.evidence.json
```

Use `agent-orca blueprint evidence` for blueprint-level decision and duration summaries.
Use `agent-orca metrics` for pass rate, evidence coverage, and top failure causes.
