---
title: Orca
---

Orca is a blueprint authoring and execution CLI for workflows that merge deterministic and non-deterministic steps.

It lets a team define a workflow once and run it with:
- deterministic checks
- non-deterministic prompts and approvals
- bounded retries
- explicit `PASS`, `WARN`, or `BLOCK` outcomes
- evidence for every run

Start with the blueprint path:
- `agent-orca blueprint lint`
- `agent-orca blueprint run`
- `agent-orca blueprint evidence`
- `agent-orca version`

## The 60-second tour

```bash
# install (from your orca checkout)
./install.sh

# validate and run a blueprint
agent-orca blueprint lint blueprints/orca-pr-default-v1.yaml
agent-orca blueprint run blueprints/orca-pr-default-v1.yaml \
  --input change_request="tighten blueprint evidence output for failed runs"
agent-orca blueprint evidence --newest
```
