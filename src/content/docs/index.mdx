title: Orca
---

Orca is the blueprint runtime and control plane for AI-assisted software delivery.

It lets a team define a workflow once and run it with:
- deterministic checks
- bounded retries
- explicit `PASS`, `WARN`, or `BLOCK` outcomes
- evidence for every run

Start with the blueprint path:
- `agent-orca check`
- `agent-orca blueprint lint`
- `agent-orca blueprint run`
- `agent-orca blueprint evidence`
- `agent-orca do`
- `agent-orca work`

## The 60-second tour

```bash
# install (from your orca checkout)
./install.sh

# in any repo
agent-orca init --preset go
agent-orca check

# validate and run a blueprint
agent-orca blueprint lint blueprints/work-default-v1.yaml
agent-orca blueprint run blueprints/work-default-v1.yaml --profile strict
agent-orca blueprint evidence --newest

# run one task through the validated work pipeline
agent-orca do "fix failing tests in queue retry flow" --mode auto --role coder
```
